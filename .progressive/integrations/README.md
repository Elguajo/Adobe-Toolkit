# Tool Integrations

This directory defines **preferred branded implementations plus stable capabilities**. Canonical machine policy is `TOOL_REGISTRY.json`; human profile policy is `PROFILES.md`.

Do not read every adapter during normal coding. Read the adapter for a tool only when selecting, installing, configuring, troubleshooting, or changing its routing policy. Installation commands are intentionally not treated as permanent truth: consult the tool's current official source before installation.
