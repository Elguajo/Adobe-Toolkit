# Notice

Progressive Context Kit is a new independent iteration inspired by
`Elguajo/Token-Efficient-Spec-Kit` (MIT). The original repository is preserved as historical and semantic reference.

**Token-Efficient · Quality-First · Spec-Driven**

Progressive Context Kit provides separate user-level global adapters for Codex and Claude Code, one vendor-neutral repository context/workflow router, progressive Skills/protocols, branded preferred-tool routing, generated Project Runtime packaging, and atomic inherited/framework contracts.

Human onboarding lives under `docs/human/` in the source distribution and is deliberately excluded from Project Runtime installs.
