# Tooling Bootstrap

Use `.progressive/prompts/SETUP_TOOLING.md` and the Tool Adapter Protocol. Route by stable capability and task evidence before brand. Preferred brands are Semble, Serena, RTK, Superpowers, gstack, Context7, and conditional GitHub Spec Kit, but each remains replaceable behind its capability and documented fallback. Installed does not mean loaded or invoked. Verify current official setup before installation; ask once before user/global configuration; persist status so later sessions do not re-ask unnecessarily.
